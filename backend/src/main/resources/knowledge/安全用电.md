# 居民安全用电基础

## 日常使用

不要用湿手操作插头、开关和电器。大功率电器应使用符合额定电流要求的独立插座，避免多个大功率设备共用插排。发现插头、插座异常发热、焦味、冒烟或火花时，应立即停止使用；在确保自身安全的前提下切断电源，并联系专业人员检查。

## 触电与线路危险

发现有人触电时，不要直接用手接触伤者。应先在安全条件下切断电源，或使用干燥绝缘物使其脱离电源，并立即联系急救。发现电线落地、设备冒烟或起火时，应远离危险区域，防止跨步电压和二次伤害，并联系当地紧急服务或供电专业渠道。

## 漏电保护

漏电保护器用于在检测到异常漏电时快速切断电路，但不能替代规范布线、接地和日常检查。建议按产品说明定期测试；频繁跳闸通常说明线路、设备或负载可能存在问题，不应反复强行合闸。
