# 阶梯电价与峰谷电价通用说明

## 阶梯电价

居民阶梯电价通常按照一个结算周期内的累计用电量划分档位。用电量进入更高档位后，超出相应边界的部分可能采用更高单价。具体档位、周期、价格、适用客户和生效日期由当地有效政策决定，不能仅凭通用知识给出某地区的确定数值。

## 峰谷电价

峰谷电价按用电发生时段采用不同价格，目的是引导负荷从高峰转移到低谷。是否开通、峰平谷时段和价格因地区、用户类别及政策版本而异。判断账单变化需要同时取得分时电量、对应时段价格和政策生效日期。

## 账单分析边界

仅有月度总电量和总金额时，可以比较环比变化和日均用电量，但不能准确判断具体电器的贡献，也不能确认变化一定由阶梯或峰谷机制造成。可靠结论需要计量曲线、费率快照和费用明细作为证据。
