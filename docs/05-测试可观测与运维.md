# 测试、可观测与运维

## 测试结构

- 单元测试：意图分类、账单解释、Markdown 切片。
- API 集成测试：健康检查、校验、401、角色权限和统一响应。
- 数据集成测试：Flyway、会话恢复、幂等响应和资源隔离。
- AI 评估：RAG Top-1 数据集门禁。
- 故障测试：LLM 连接失败及失败指标。
- 前端测试：登录成功/失败 API 行为。

常用命令：

```powershell
cd backend
mvn clean test

cd ../frontend
npm ci
npm test
npm run build
```

## 可观测性

`RequestTraceFilter` 接受合法的 `X-Request-Id` 或生成 UUID，把它写入 MDC、响应头和统一
响应。日志记录 method、path、status、durationMs，但不记录密码和 Token。

Actuator 提供 readiness、liveness 和 metrics。指标接口只允许 ADMIN。核心 LLM 指标见
生产化运行手册；Prometheus 与告警规则位于 `infra/observability`。

## CI

GitHub Actions 执行后端 verify、前端 clean install/test/build、Trivy 文件系统扫描、镜像构建
和镜像扫描。Dependabot 跟踪 Maven、npm 和 Actions 更新。真实仓库还应开启分支保护，要求
CI 全绿后才能合并。

## 部署与恢复

Dockerfile 先构建 Vue，再将 dist 放入 Spring Boot 静态资源，最终镜像使用非 root 用户和
健康检查。Compose 启动应用、MySQL、Redis、Keycloak 和可选消息设施。

数据库只由 Flyway 迁移。备份、恢复、Keycloak 初始化、候选发布和回滚脚本位于 `scripts`。
脚本存在不等于演练完成；必须在有 Docker 的隔离环境实际执行并记录结果。
